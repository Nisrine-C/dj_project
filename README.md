# DJ Portfolio & Booking Web App

A modern, responsive portfolio and booking website for DJs built with React.


## Features

- **Homepage/Landing:** Showcase DJ bio, services, events, and visuals
- **Booking Page:** Simple interface for potential clients to book your DJ services
- **Component-Based UI:** Reusable and extendable React components for maintainability
- **Responsive Design:** Looks great on desktop and mobile
- **Image Assets:** Visual elements for branding and demonstration


## Project Structure

```
src/
├── assets/               # Images, SVGs, and other assets
├── components/           # Shared UI components
├── images/               # Additional images and visual content
├── pages/
│   ├── Booking/          # Booking form and related styles
│   └── home/             # Main landing page, homepage components
├── App.jsx
├── App.css
├── index.jsx
├── root.css
└── images.js
```


## Getting Started

1. **Install dependencies**
   ```bash
   npm install
   ```
2. **Start the development server**
   ```bash
   npm start
   ```
3. Navigate to [http://localhost:3000](http://localhost:3000) to view the app.

## Customization

- Update DJ information, services, bio, and event details in `/src/pages/home` and `/src/pages/Booking`
- Place your images in `/src/assets` and reference them as needed
- Adjust styles in `App.css`, `root.css`, and individual component CSS files

## Deployment

You can deploy this project using Vercel, Netlify, or GitHub Pages.
